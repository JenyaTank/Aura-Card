# Aura Card

8 questions. 1 card. No refunds.

Answer 8 dumb questions, get a FIFA-style player card about yourself: OVR, rarity (Bronze → Icon) and 6 stats — AUR, RIZ, CHL, GRS, SLP, ROT.

- One file: `index.html`. No server, no build, no accounts.
- Your photo stays on your device. The share link only has your name + answer numbers: `?n=NAME&a=01230123`.
- Send the link to a friend → they play → you get a stat-by-stat battle.
- "Save story image" makes a 1080×1920 PNG for TikTok / Insta / Shorts.

## Publish (GitHub Pages)

1. New repo on GitHub → "uploading an existing file" → drop `index.html` → Commit.
2. Settings → Pages → Branch: `main` → Save.
3. Wait a minute, your link appears at the top of that page.

Works on Netlify Drop too (just drag the folder).
